# Laravel POS Project

## Setup Instructions

1. Clone the repository.
2. Run `composer install`
3. Copy `.env.example` to `.env` and update DB settings
4. Run `php artisan key:generate`
5. Run `php artisan migrate`
6. Run `php artisan serve`
